# Unwrap 
Unwrap is a group project designed to help Spotify users explore their listening history and personal music statistics.

The group project was started before I joined. This repository contains my attempt to develop the frontend for Unwrap as part of my web frontend coursework.

## Current features
- Landing Page
- About Page
- Statistics dashboard prototype
- Clickable Unwrap logo
- Sample statistics data

## Technology
This project currently uses:

- HTML for page structure
- CSS for styling
- JavaScript for interactions
